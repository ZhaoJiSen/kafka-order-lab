## 代码阅读核对

订单及待发送事件在 PHP 本地事务中保存；Java 将去重记录、审核结果与结果 Outbox 一起提交。两端消费者在本地处理完成后才推进 Kafka 消费位置。发送确认和 Outbox 标记之间仍可能出现重复，代码与文章都保留了事件去重与业务状态保护的说明。

README、实际配置和代码入口已对照；没有把 Kafka 写入确认当作跨服务业务完成，也没有把观察服务的位置当成业务消费者内部的读取位置。真实密钥与运行数据未用于示例模板。

## 已知边界

- 本次没有运行会创建订单、启停服务或重置消费组的真实链路 smoke，避免改变正在使用的实验环境；本次通过的是上述自动测试、初始化和构建检查，不声称重新完成端到端故障演练。
- 全新机器的 Homebrew / PECL 安装说明已参考官方文档；本次验证环境已有运行时，没有在另一台空白系统重新安装 PHP、JDK 或 Kafka。
- 单 Broker、单副本、两端业务单实例；不是生产部署模板。
- Java 对可重试异常无限重试，可能阻塞后续消费；没有实现重试 Topic、死信、生产告警或自动补偿。PHP 本机消费命令遇错退出后需修复并重启。
- 使用外部或本机 Kafka 时，页面无法通过本地 Docker 读取其 Broker 日志；消息与进度观察仍可连接配置的 Broker。
- Vite 构建主 JavaScript 包约 808 kB（gzip 约 255 kB）；当前用于本机教学，后续可以按页面拆包。
- 测试中的 Mockito agent 提示、Node / KafkaJS 兼容提示不代表已经完成未来版本兼容性验证。

本报告记录本次实际检查，不替代生产环境的安全评估和压测。
